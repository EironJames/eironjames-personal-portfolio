MINDSU PERSONAL PORTFOLIO
=========================

FILES
-----
index.html
    The HTML document containing the portfolio content and page structure.

style.css
    The external CSS file containing the website's colors, fonts, spacing,
    borders, and other presentation rules.

index.html.code
    A plain-text copy of the complete HTML source code.

images/profile.png
    The profile photograph used in the About Me area.

STEP_BY_STEP_CODE_GUIDE.txt
    A beginner-friendly explanation of how the portfolio was built using
    the topics covered in Unit 8.

HOW TO OPEN THE WEBSITE
-----------------------
1. Extract the ZIP file.
2. Open the MinSu_Portfolio_Unit8 folder.
3. Keep index.html, style.css, and the images folder together.
4. Open index.html using a web browser.

HOW TO EDIT PERSONAL INFORMATION
---------------------------------
1. Open index.html in a text editor.
2. Find the text you want to change.
3. Replace it with your updated information.
4. Save the file and refresh the browser.

HOW TO CHANGE THE PROFILE PHOTO
-------------------------------
1. Put your new picture inside the images folder.
2. Name it profile.png, or update the image file name in index.html.
3. Keep the image path correct.

LESSON LIMIT
------------
This version intentionally uses basic HTML and CSS topics from Unit 8.
It does not use JavaScript, CSS Grid, Flexbox, media queries, CSS
animations, or interactive modal windows.
